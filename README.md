# Andrey Santos | Adestramento comportamental

Site estático em HTML, CSS e JavaScript. Depois de extrair o ZIP, abra o arquivo `index.html` no navegador para conferir o site.

## Publicar no GitHub Pages

1. Envie os arquivos extraídos, incluindo a pasta `assets` e o arquivo `.nojekyll`, para a raiz do branch `main` do seu repositório.
2. Abra `Settings → Pages` e selecione `Deploy from a branch`.
3. Escolha o branch `main` e a pasta `/(root)`, depois salve. O endereço aparece na tela do Pages quando a publicação termina.

[Documentação do GitHub Pages](https://docs.github.com/pt/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
